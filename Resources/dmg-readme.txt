Chiikawa in my Mac — 먼저 읽어 주세요
====================================

화면 위에 떠 있는 우사기에게 말을 걸면 AI(Claude · Codex)가 대신 답해 주는 앱입니다.


1. 설치
-------
Chiikawa_in_myMac 을 옆의 Applications(응용 프로그램) 폴더로 끌어다 놓습니다.


2. 처음 열 때
-------------
Apple 에 등록한 개발자의 서명이 없는 앱이라, 처음 열면 "열 수 없습니다" 또는
"손상되었습니다" 라는 경고가 뜹니다. 아래 둘 중 하나를 한 번만 하면 됩니다.

  방법 A (터미널)
    터미널을 열고 아래 한 줄을 붙여 넣은 뒤 return 을 누릅니다.

      xattr -dr com.apple.quarantine /Applications/Chiikawa_in_myMac.app

    그다음 응용 프로그램 폴더에서 Chiikawa_in_myMac 을 엽니다.

  방법 B (시스템 설정)
    앱을 한 번 열어 경고를 닫은 뒤,
    시스템 설정 → 개인정보 보호 및 보안 → 아래쪽의 "그래도 열기"를 누릅니다.


3. 준비물
---------
우사기는 내 Mac 에 설치된 AI 프로그램을 대신 실행해 줍니다. 둘 중 하나가 필요합니다.

  - Claude Code : 터미널에서 claude 가 실행되고 로그인까지 끝난 상태
  - Codex       : 터미널에서 codex 가 실행되고 로그인까지 끝난 상태

없어도 우사기는 뜨지만, 질문에 답하지는 못합니다.


4. 쓰는 법
----------
  - 처음 켜면 폴더를 고르는 창이 뜹니다. AI 가 읽을 폴더를 고릅니다.
  - 우사기를 누르면 말풍선이 열립니다. 질문을 적고 return.
  - 우사기를 끌면 옮겨집니다.
  - 메뉴바의 우사기 아이콘(또는 우사기를 마우스 오른쪽 버튼으로 누르기)에서
    AI 고르기, 소리 끄기, 혼잣말 끄기, 종료를 할 수 있습니다.
  - Dock 에는 아이콘이 생기지 않습니다.


5. 개인정보
-----------
  - 이 앱은 claude · codex 를 실행만 합니다. 로그인 정보를 읽거나 고치지 않습니다.
  - 이 앱이 따로 모으거나 다른 곳으로 보내는 것은 없습니다.
  - 대화 기록은 고른 폴더의 .chiikawa_in_mymac/session.json 에,
    설정은 ~/.config/chiikawa_in_mymac/config.json 에만 저장됩니다.
